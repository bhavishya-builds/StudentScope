# OppTrack

OppTrack is a student-focused platform that brings scholarships, internships, hackathons, competitions, entrance exams, and counselling information together in one place.

The main idea behind the project is to reduce the need for students to check multiple websites for opportunities and important deadlines.

## Features

- Browse scholarships, internships, hackathons and competitions
- Search and filter opportunities
- Track entrance examination information
- View counselling portals and important dates
- Counselling round and deadline tracking
- Direct links to relevant opportunities
- Clean and responsive interface
- Student-focused dashboard

## Why I Built It

Students often have to visit different websites to find scholarships, internships, hackathons, exams and counselling updates. I wanted to build a single platform where these opportunities could be organized and accessed more easily.Also like i personally suffer with this problem so basically i want to solve my own problem :)
